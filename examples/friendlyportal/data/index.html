A whole website
on a tiny box.

FriendlyPortal is a live demo of Roost — an open-source “captive-portal appliance in a box.” Everything you see is served from one small device with no internet connection: a welcome portal, games, and this documentation itself.

📶 Captive portal 🌐 Own DNS 🔒 HTTPS 🖥️ SSH shell 📊 Live console

What this box is doing right now

📶

Captive portal

When you joined the Wi-Fi, your device probed for internet. This box answered and popped up this page — the classic “sign-in” portal, but friendly.

🌐

Its own DNS

Every web address you type resolves to this box. That’s how friendlyportal.local works with no internet behind it.

🔒

Real HTTPS

It can serve a real, trusted certificate for its domain — the padlock is genuine, even though the site lives in your pocket.

🖥️

A tiny shell

SSH in and you get a little command line: status, top, tail, ls, help. Watch visitors in real time.

📊

Live console

A dashboard shows every web hit and DNS lookup as it happens — see the portal working live.

📦

It’s just a folder

This whole “OS” is an image: a folder with a config file and these web pages. Copy it, edit it, make your own.
